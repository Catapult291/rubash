# Brand Assets

Rubash's logo belongs to the unixwin shell family alongside niubash (gold
bull on navy) and WinuxCmd (green `W` on charcoal). Shared DNA: a dark
rounded-square tile, one accent color, bold geometric strokes with round
caps, and a terminal-cursor element.

Rubash's identity is the **engine core**: a segmented cyan rotor ring (the
engine/flywheel) around a lowercase `r`, with a block cursor — the engine
inside niubash, not a terminal app. Cyan (`#08f8f8` -> `#38b6ff`) completes
the family's green / gold / cyan palette; it is the unused third of the
niubash banner gradient.

## Files

| File | Use |
| --- | --- |
| `assets/rubash-icon.svg` | Master icon (vector source, hand-drawn) |
| `assets/rubash-icon-512.png` / `-256.png` / `-64.png` | Raster renders |
| `assets/favicon.ico` | 16/32/48 px frames, bold-stroke variant |
| `assets/rubash-lockup.svg` | Horizontal lockup (icon + wordmark + tagline) |
| `assets/proposals/` | Alternate directions kept for the record |

## Backgrounds

The icon carries its own navy tile, so a single asset works on both light
and dark surfaces. On dark surfaces the `#2a3a60` hairline keeps the tile
edge readable; on light surfaces the tile provides contrast on its own.
For favicon use, `favicon.ico` frames are rendered from a bold-stroke
variant so the `r` stays legible at 16 px.
